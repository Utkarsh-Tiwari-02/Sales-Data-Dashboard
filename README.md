# Sales Dashboard (Excel)

## 📊 Project Overview
This project presents an interactive Sales Dashboard built in Microsoft Excel to analyze sales performance, regional trends, product performance, and profit insights.

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts (Column Chart, Pie Chart, Bar Chart)
- Slicers

## 📈 Key Insights
- Monthly Sales Trend
- Region-wise Performance
- Top Performing Products

## 📂 Dataset
Sample sales dataset containing order date, region, product, sales, amount and profit.
